# Quiz final — Windows Data Acquisition

Résultat : 68 points, terminé.

## Questions et réponses

**Q1. What are the temporary data that can be collected on the Windows operating system?**
→ **RAM contents, CPU caches, system logs, and network connection information** (données volatiles)

**Q2. Which storage media are used to store persistent data, called non-volatile data?**
→ **Hard disks (HDD, SSD), USB flash drives, CDs/DVDs**

**Q3. What is the main purpose of Live Data Acquisition?**
→ **Securely copying data from a running computer**

**Q4. What information is extracted from the contents of RAM during live data acquisition?**
→ **Running processes, open files, system and application settings**

**Q5. What is the main purpose of Microsoft Sysinternals tools?**
→ **Deeply managing and troubleshooting the Windows operating system**

**Q6. What is the main purpose of the Volatility tool?**
→ **Analyzing memory dumps**

**Q7. What is the importance of Dynamic Acquisition in forensics?**
→ **Capturing the events taking place in a live system and the current state of the system**

**Q8. Which of the following is not one of the Dynamic Acquisition methods?**
→ **Bit-by-bit data copying** (c'est une méthode de Copy/Duplicate, pas de Dynamic Acquisition)

**Q9. Which SysInternals tool can be used to collect information about the processes in the running system and to get a memory dump of a process when needed?**
→ **Process Explorer**

**Q10. Which SysInternals tool is used to view the details of applications set to run automatically on the Windows system under investigation?**
→ **AutoRuns**

**Q11. Which Windows Tool is used to examine the Windows Registry and take a dump if necessary?**
→ **Regedit**

**Q12. What is a data copy method where each bit of data is copied individually?**
→ **Bit Level Copy**

**Q13. Which of the following is not one of the Bit Level Copy methods?**
→ **Directory Copy** (les méthodes réelles sont Sector Copy, File Copy, Memory Copy)

**Q14. Which of the following software can be used to take both memory images and disk images in the Windows operating system?**
→ **FTK Imager**

**Q15. Which of the following commands can be used to calculate the hash value of a file in the Windows operating system?**
→ **certutil**
